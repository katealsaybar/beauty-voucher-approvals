Read before you review 4 notes
Fonts and logo are now correct in the files themselves.
All thirteen emails are set in Georgia,'Times New Roman',serif for headlines and 'Inter',Arial,sans-serif for body copy, so nothing depends on a webfont loading. The button labels ask for 'Playfair Display' first at weight 400, with Georgia behind it, so Apple Mail and these previews show Playfair and Gmail and Outlook fall back to Georgia regular. Either way the label is no longer bold. The logo is no longer an image: the wordmark is typeset in live text, so it still reads when a client blocks images and there is no hosted file to go missing. When these are pasted into GHL, do not let the builder re-style the headings back to a webfont.
Why the shorter WhatsApp message is the only one we can send.
WhatsApp is not email. Any message we send to a client who has not written to us first has to be submitted to Meta and approved before it can go out at all, and Meta caps the message at 1,024 characters. Our Abu Dhabi broadcast came to 1,193. Over the cap, Meta does not trim it and does not warn us later: it simply refuses the message, so the step would sit in the workflow with nothing to send and the client would hear nothing. Same rule on the buttons: each one is capped at 25 characters and two of ours were 26. So the shorter version is not a style choice, it is the only version that can exist. The voucher link carries the three tiers instead, which reads better on a phone anyway. You can still read the longer draft: open any WhatsApp step and switch to Longer draft, and it will tell you it cannot be submitted.
